# Life OS 界面主题设计规范

## 设计边界

Life OS 的主题系统位于页面表现层。切换主题只改变色彩、字体族、圆角、边框、阴影、背景纹理、图标描边和局部装饰，不改变模板中的信息顺序、表单字段、业务状态、REST API、领域服务或 SQLite 模型。日期状态、危险操作、保存结果和键盘焦点在每套主题中都必须保留文字或形状提示，不能仅靠颜色区分。

七套主题共用一个语义 DOM 和一组组件，使用 `<html data-theme="…">` 选择主题。主题标识只允许为 `default`、`bamboo`、`indigo`、`water`、`neumorphism`、`macos-glass` 和 `ghibli`。主题选择保存为 `life-os.theme` 界面偏好；桌面模式同时使用当前端口的 LocalStorage 和同一 WebView 配置中的本地 Cookie，以跨越随机端口重启，两者都位于 `LIFE_OS_HOME/cache/webview/`，不是业务数据，也不新增数据库表或 API。

项目品牌统一使用 `assets/branding/logo-concepts/life-os-logo-02a-ref-a-full-landscape-contained.png`。正式页面使用其原样复制的本地 PNG，桌面构建脚本从同一源文件生成多尺寸 ICO；主题不得替换 Logo 结构，只可通过周围留白和背景适配其显示。

## 共用交互规则

主题选择器固定放在共享导航内，包含可见标签、七个中文选项和“只改变外观，不改变数据”的说明。选择后页面立即切换，不刷新、不发起业务请求；重新启动时先读取当前端口 LocalStorage，缺失时读取本地 Cookie，从而恢复上次选择。存储不可用时仍允许本次会话切换，并在下一次启动回退为“默认”。所有主题继续遵守 `prefers-reduced-motion`，不增加持续动画、网络字体、远程图片或在线图标。

## 默认

默认主题延续现代东方极简基线。暖白 `#F5F3ED` 作为背景，青黛 `#3F625F` 作为主要操作色，天青 `#729B99` 作为信息强调，朱砂 `#B95549` 只用于休息日、错误与少量警示。模块采用低饱和分区浅底、细边框和轻阴影；英文与数字以 Times New Roman 为主，中文回退到系统宋体或黑体。图标保持 1.7px 圆角线性描边，按钮使用小幅位移反馈。该主题作为无偏好、偏好失效和新运行时目录的稳定回退。

## 古风竹青

古风竹青以纸本、竹叶与温润木色为视觉意象。`#789262` 是明确的主配色，搭配暖宣纸 `#F1F0E3`、象牙纸面 `#FBF8EC`、墨绿 `#273426`、木赭金 `#A77D48` 与朱砂 `#A65343`，不是通过同一绿色的明暗变化拼成界面。状态、专注、节律、习惯、记录和财务模块分别借用灰竹、麦色、水青、嫩叶、浅陶与茶纸色形成克制的综合色阶。标题使用仿宋/宋体回退，正文优先宋体；模块采用小圆角、竹青左侧线、木色上边线和右上双短线印记，形成纸本册页感。线性图标收细到约 1.45px，不使用复杂花纹、书法图片或仿古素材。

## 古风藏青

古风藏青以 `#2E4E7E` 为主配色，强调稳重、秩序和蓝布封面的册页感。固定侧栏使用更深的 `#243E63`，与瓷白纸面 `#F8F6F1`、深蓝墨 `#17263B`、铜金 `#A9834D`、松石绿 `#4E7167`、朱砂 `#A94F4C` 和少量藕紫共同构成综合色板；选中导航以铜金边线、半透明亮层和白字同时表达，不把整页简化为蓝色明度阶梯。正文区域仍保持浅色阅读，模块按蓝灰、铜纸、水蓝、松灰、藕灰和浅铜色分区。图标采用细线、端点圆润的“工笔”感，财务数字保持等宽数字特性。

## 古风水色

古风水色以 `#88ADA6` 为主配色，使用江南水面、雾气和浅玉色的轻盈层次。它与雾白 `#EDF6F4`、水墨 `#233D39`、远山蓝 `#709BAD`、柳叶绿 `#5D8874`、莲藕灰紫、沙金 `#AA8B58` 和珊瑚朱 `#B45F52` 搭配，形成水、岸、草木与花色之间的综合色阶。背景使用白雾光斑、淡蓝水影和极弱斜向波纹；模块保持小圆角、天青边线和柔和大范围阴影。标题使用仿宋，线性图标采用细描边，选中状态通过边框、浅底和文字粗细三重表达。

## 财务模块配色

财务页面不直接把全局主色套到所有数字上，而使用稳定的语义色 Token：资产为冷青蓝，负债为低饱和赭红，收入为沉静草木绿，支出为朱砂，转账与净现金流为灰紫，普通财务边界和期间信息为铜金。每套主题可以调整这些颜色以融入自身色板，但不得交换语义。资产概览卡通过顶部色线和金额颜色双重区分；账户、余额和流水通过左侧色线、类型文字及标签共同表达，因此在低色觉辨识条件下仍可依靠“资产/负债/收入/支出/转账”文字判断。财务背景不使用渐变；总览、收支流水和账户分别使用三种协调但不同的纯色表面。竹青主题使用茶纸、嫩叶和水青，藏青主题使用雾蓝、松灰和藕紫，水色主题使用浅玉、水草和远山蓝，从而避免两个相邻模块重复使用棕黄色。

## 新拟物派

新拟物派采用统一冷灰蓝基面 `#E7ECF0`，依靠成对的亮部与暗部阴影建立凸起和凹陷关系。卡片、侧栏和按钮不使用明显实线边框，模块圆角增大到约 1.35rem；输入框、选中导航和部分状态区使用内阴影，按钮和普通卡片使用外阴影。主色为克制的灰青 `#4F716F`，正文为 `#26333B`。所有可操作元素仍保留焦点环和文字标签，不能仅依靠“凸起感”表示可点击；错误、禁用与选中状态继续使用文字和色彩辅助。图标描边略增粗到约 1.9px，以适应柔和背景。

## macOS 毛玻璃

macOS 毛玻璃主题以半透明层、背景模糊和柔和环境色组织层级。页面底层使用青绿、天蓝和暖橙的固定径向渐变，侧栏、顶栏与模块使用 48%–60% 的白色透明表面、约 22px 的 `backdrop-filter` 模糊和轻柔大范围阴影。主色为 `#426F78`，正文为 `#20303C`，模块圆角约 1.15rem；字体优先系统 UI 字体。浏览器不支持背景模糊时，半透明背景和边框必须仍可读。图标保持约 1.65px 线性描边，不复制系统专有图标，也不模拟窗口交通灯或系统标题栏。

## 吉卜力风格

吉卜力风格采用温暖手绘动画般的自然氛围，不复制任何具体角色、场景或受保护画面。背景由浅天空 `#D8EDF0` 向奶油纸色 `#F5ECD7` 过渡，并以纯 CSS 白色云团形成轻量环境层；主色为森林绿 `#3F6C50`，水色为 `#74AEBA`，朱橙为 `#C8664F`，阳光金为 `#D0A044`。卡片使用较厚米色边框、大圆角和轻微下沉阴影，标题优先楷体回退，并以小型金色叶点作结。图标使用约 2px 圆润描边，悬停只做短促旋转与缩放；不使用角色剪影、影视截图、纹理图片或长动画。

## 响应式、可访问性与验收

主题选择器在固定侧栏中纵向显示；侧栏转为顶部导航时改为横向布局；窄屏下回到单列并隐藏辅助说明，但保留标签和选择框。七套主题均需检查 Today、Calendar、错误提示、表单、日历选中、休息日、键盘焦点和滚动区域，不得改变现有断点或产生横向溢出。

主题系统的最低验收包括：七个选项均可即时生效；刷新和桌面重启后恢复选择；清空 WebView 缓存后回到默认；切换过程中不发起 `/api` 请求、不修改 SQLite 或 `settings.json`；Logo 从本地静态资源加载；冻结包包含主题 CSS、主题脚本和 Logo；七套主题均能在 1280px、768px 与 375px 宽度下完成基本阅读与键盘操作。

## 里程碑归属

- M1 提供版本化本地静态资源、统一 Token、`cache/webview/` 和无构建前端入口。
- M2 明确主题偏好不进入 SQLite，不修改任何领域模型或 schema。
- M3 明确主题切换不新增 API，不绕过现有业务接口。
- M4 提供选择器、七套主题 Token/组件装饰、Logo 和响应式行为。
- M4.5 将全部主题资源与 Logo 收入 `onedir`，并以同一 Logo 生成 Windows EXE 图标；桌面偏好随 WebView 缓存目录管理。
