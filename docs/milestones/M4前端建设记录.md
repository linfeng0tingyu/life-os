# Life OS M4 前端建设记录

## 建设范围

M4 在既有 Flask/Jinja 与同源 API 基线上完成基础界面和日期导航，不引入 Node.js、前端构建器、CDN 或第三方运行时依赖。实现包含随视口铺满可用宽度的侧栏与主内容布局、只呈现本地当天的 Today Dashboard、独立日历与任意日期详情页、未来任务快速规划、日期属性编辑、统一 API Client、页面级日期状态以及加载、空、错误、保存中、已保存和保存失败反馈。

任务与习惯在本阶段读取并展示日期聚合结果；为满足未来规划，日历页额外提供把任务直接安排到未来所选日期的轻量入口，完整编辑闭环仍留给 M5。健康、日记与财务在本阶段展示只读摘要或稳定容器，完整保存与统计界面留给 M6。这一边界避免在 M4 重复实现后续领域交互，同时保证首页信息结构和页面模块位置已经稳定。

Today 与 Calendar 共用的生活节律概览固定为睡眠时长、体重、运动和身体健康四项，不在日期总览中展示睡眠时段、睡眠质量、精力、情绪或健康备注；这些字段仍由既有 API 和数据库完整保留，后续在独立生活节律板块中展开。

## 工程结构

样式按 `tokens.css`、`base.css`、`layout.css`、`components.css`、`pages/today.css` 和 `pages/calendar.css` 顺序加载，核心颜色、字体、间距、圆角与阴影只在 Token 层定义。配色和按钮反馈依据 `assets/design-prototypes/` 校准；共享导航与操作按钮使用统一的 1.7px 线性 SVG 描边，不再使用字符占位图标。

JavaScript 使用原生 ES Modules。`api/client.js` 统一处理同源读写请求、JSON 合同、超时、请求取消、连接失败、HTTP 错误和 `X-Request-ID`；`pages/today.js` 固定读取设备本地今天；`pages/calendar.js` 管理可回溯的日期 URL、过去/今天/未来状态、未来计划写入、旧请求取消与最后响应生效规则；`features/calendar.js` 管理月历、日期选择和日期标记表单；Today 与 Calendar 共用 `day-dashboard.html` 和 `DaySummary`，避免历史详情降级成简略统计。

## 接口补充

`GET /api/calendar/month/{year-month}` 在原日期分类字段外新增两个轻量字段：`has_data` 表示该日存在显式日历标记或任务、习惯日志、健康、日记、财务流水；`habit_summary` 返回当前启用习惯的完成数与总数。该设计让月历一次请求即可显示数据提示和最小习惯摘要，避免每月发起约三十次完整日期聚合请求。

## 状态与错误处理

切换日期会取消尚未完成的旧请求，并以请求序号阻止迟到响应覆盖新日期。读取错误在页面顶部展示用户可理解的信息和重试按钮；若后端返回请求编号，错误信息会保留该编号用于排查。日期标记只有明确提交后写入；保存失败时不清空输入，并恢复表单可编辑状态。页面业务数据不写入 LocalStorage 或 IndexedDB。

## 验证结果

- 90 项 pytest 测试全部通过，包括今日/日历页面边界、未来任务聚合、月历轻量摘要、HTML 入口和全部本地静态资源。
- 浏览器默认打开本地今天，今日页不包含月历或日期标记；独立日历页允许连续访问过往月份，并可通过月份选择器直接跳转历史年月。
- 任意日期选择只更新 URL、完整日详情与标记表单，不整页刷新；过去日期可完整回看各领域数据，未来日期可创建当天计划，标记或计划保存后同步更新月历与日详情。
- 上月、下月与返回今天行为正确；键盘 Tab 可进入主导航，表单具备可读标签和动态文字状态。
- 人工停止本地服务后，页面显示连接失败和重试入口；服务恢复后点击重试即可重新进入已载入状态。
- 主内容不再受 88rem/74rem 固定上限截断，随设备视口占满侧栏之外空间，并在超宽屏自动切换日详情双列；2560px、1920px、1280px、768px 和 375px 视口均无横向溢出，窄屏保持单列。导航与全部操作按钮均具有可见、尺寸一致的线性 SVG 图标。
- 浏览器控制台无错误；页面运行未请求 CDN、远程字体、分析服务或其他外部资源。

## 后续边界

M5 应在现有任务与习惯容器中增加创建、编辑、排序、状态切换、归档和失败回滚，不改变日期状态与 API Client。M6 应在现有节律、日记和财务容器中加入防抖保存、未保存保护、明确提交记账和总体财务摘要，并继续复用当前状态文案与错误模型。

## 2026-09-20 主题与品牌增量

M4 在不改变 Today/Calendar DOM 语义、数据请求和响应式断点的前提下增加七套主题。共享侧栏新增可访问的主题选择器；`theme.js` 校验主题白名单、即时设置 `data-theme`、更新窗口主题色并把选择保存为可丢弃偏好；`themes.css` 分别实现默认、古风竹青、古风藏青、古风水色、新拟物派、macOS 毛玻璃和吉卜力风格。各风格独立定义色板、字体、圆角、阴影、背景与图标描边，不读取 `assets/design-prototypes/` 中的尝试版 HTML。

侧栏旧 CSS 圆环标记已替换为 `src/life_os/static/images/life-os-logo.png`，其内容与指定 `assets/branding/logo-concepts/life-os-logo-02a-ref-a-full-landscape-contained.png` 完全一致。主题切换脚本不导入 API Client、不调用 `fetch`，因此不会修改任务、习惯、健康、日记、财务或日期标记。

主题增量完成后，全量 pytest 为 101 项并全部通过；新增测试覆盖七套选项、主题白名单、本地偏好键、无 API 调用、主题 CSS、Logo PNG 和新增静态资源。
