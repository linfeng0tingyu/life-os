# Life OS M5 任务与习惯闭环建设记录

## 阶段结论

M5 已完成任务与习惯的主要管理闭环。系统在既有领域服务和统一 REST API 上增加独立的“任务”与“习惯”页面，并把高频完成操作接回 Today 与 Calendar 的共用日期详情组件。2026-09-21 的交互增量新增 `categories` 表并把 schema 升至 v3，任务与习惯分类成为可创建、分作用域的单选项；运行时目录、前端体系和桌面通信边界不变。

## 任务闭环

`/tasks` 提供有日期与无日期任务的新建和编辑，可维护标题、说明、状态、优先级、分类、计划日期、截止日期和父任务。新增/编辑表单默认隐藏，点击按钮后才在页面内模态窗口出现。分类改为任务作用域的单选列表，并可在窗口内创建后立即选中。列表支持搜索、状态筛选、日期筛选、排序、开始、完成、取消、重新打开、归档以及显式显示已归档任务。

新增 `POST /api/tasks/{id}/restore` 作为明确的归档恢复入口。归档仍为软删除：默认查询与日期聚合排除归档项，`include_archived=true` 可以查询，恢复后继续使用原任务记录。恢复重复调用保持幂等，不存在的任务返回 404。

## 习惯闭环

`/habits` 提供习惯名称、说明、分类和图标类型的新增与编辑，并支持排序、停用、显示已停用项和恢复。新增/编辑也使用默认关闭的模态窗口；习惯分类与任务分类分开读取和创建，均为单选。用户可以选择今天或任意过去日期即时切换完成状态；未来日期不允许提前产生完成日志。

完成切换继续使用 `PUT /api/habits/{id}/log/{date}` 的按日 upsert。前端在切换布尔状态时保留既有 `value`、`value_unit` 和 `note`，不会因为快速打卡覆盖详细记录。停用习惯只从默认清单和每日打卡区隐藏，历史日志保持不变，恢复后继续使用原习惯及其历史。

## 日期详情联动

Today 与 Calendar 的共用日期详情组件增加任务完成/重新打开和习惯完成/撤销按钮。操作成功后重新读取对应日期聚合，确保摘要、标签和列表来自同一个后端状态；未来日期只允许调整任务，不允许写入习惯完成记录。任务页与习惯页继续复用统一 API Client、保存状态、错误提示和主题 Token。

Calendar 页首“回到今日”现与 Today 页“查看日历”互为模块导航，直接返回 `/`；月历工具栏中新增“回到今天”，由它执行受控异步定位。从远月份返回时同时等待月历数据和今日详情完成，地址栏、月份标题、选中日期与详情标题统一落在本机今天。未来计划中的任务分类也复用任务单选分类组件。

## 品牌尺寸

侧栏 Logo 的 CSS 显示尺寸由 2.6rem 提高至 3.25rem，窄屏由 2.4rem 提高至 3rem。首次放大仍受源图近乎透明的边缘像素影响；修正后的桌面 ICO 生成器以 Alpha 8 为可见阈值裁掉杂散边缘，再把主体放大到 1000/1024 画布，使任务栏视觉占比接近 Chrome、ChatGPT 等常用应用图标。

## 重复操作与错误恢复

任务、习惯资料和每日打卡分别维护进行中集合；同一记录的写请求未结束前，相应控件会被禁用，重复触发直接忽略。后端唯一约束 `UNIQUE(habit_id, date)` 和 upsert 语义仍是最终防线，因此界面重复点击和请求重试不会生成第二条每日习惯记录。失败时保留表单输入或既有显示状态，并显示可重试错误。

## 验证结果

- 全量自动化测试为 111 项，全部通过。
- JavaScript 语法检查通过，覆盖任务页、习惯页、Today、Calendar、日期详情组件和启动分发模块。
- 任务界面完成新建、完成、归档、显示已归档和恢复的桌面窗口流程验收。
- 习惯界面完成新建、当日打卡、停用、显示已停用、恢复及 Today 快速撤销/完成联动验收。
- 刷新后数据仍从 SQLite 读取；归档任务默认隐藏但可查询，停用习惯的当日历史在恢复后保持。
- schema v1/v2 到 v3 的迁移会按任务/习惯作用域回填既有分类；分类 API、跨作用域拒绝和未知分类拒绝已有自动化覆盖。
- 浏览器实机验收确认：任务与习惯表单初始隐藏；两类分类可分别创建并单选保存；页首“回到今日”返回 Today；从 2030 年未来日期点击月历内“回到今天”后，URL、月历与完整日期详情统一回到 2026-09-21。
- PyInstaller `onedir` 便携包已重新构建为约 38.1 MiB；冻结包包含分类组件、两类模态模板、修复后的日历与 schema v3，`LifeOS.exe --check` 在独立运行时目录初始化成功，发行目录不携带默认用户数据。

## 后续边界

M5 不实现重复任务、子任务专用界面、提醒、复杂看板或习惯趋势统计。健康、睡眠、日记和财务的完整编辑闭环继续归 M6；备份、导出和跨设备恢复演练归 M7–M8。
